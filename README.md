# ระบบหาครูแลกคาบสอน (ภาคเรียนที่ 2/2569)
### โรงเรียนพูลเจริญวิทยาคม

เว็บแอปพลิเคชันแบบไฟล์เดียว (`ระบบแลกคาบสอน 2569-2.html`) สำหรับค้นหาครูที่สอนห้องเดียวกันเพื่อแลกคาบสอนหรือสอนแทน พร้อมตรวจสอบคาบสอนคืนและสถานะคาบคู่

## ข้อมูลในระบบ
- **ภาคเรียน**: 2/2569 (อัปเดตจากชุดตารางครูย้าย 22 พ.ย. 2569)
- **จำนวนครู**: 128 คน ครบทั้ง 11 กลุ่มสาระการเรียนรู้
- **จำนวนรายการคาบ**: 3,315 คาบย่อย (รองรับคาบ 0–10)
- **คาบคู่ (Double Periods)**: 411 กลุ่มคาบคู่ (270 กลุ่มคาบสอนจริง + 141 กลุ่ม PLC/ประชุมวิชาการ) แสดงแถบกำกับ `คู่ X-Y` และตรวจสอบให้ว่าครูผู้สอนแทนว่างครบทั้ง 2 คาบหรือไม่
