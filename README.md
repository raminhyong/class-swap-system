## ✨ ฟีเจอร์หลัก

1. **ค้นหาครูแลกคาบ / สอนแทน (แท็บ `ค้นหาครูแทน`):**
   - ค้นหาชื่อครูแบบ Autocomplete พร้อมแสดงชื่อกลุ่มสาระการเรียนรู้กำกับ
   - เลือกวัน (จันทร์–ศุกร์) และคลิกคาบที่ไม่สะดวกสอน (คาบ 0–10)
   - ระบบค้นหาครูท่านอื่นที่ **สอนห้องเรียนเดียวกัน** และ **ว่างในคาบดังกล่าว**
   - จัดกลุ่มผลลัพธ์อัตโนมัติ:
     - `✅ สามารถสอนคืนได้`: ครูผู้สอนแทนมีคาบสอนห้องนั้นในวัน/คาบอื่น ซึ่งตรงกับคาบว่างของครูผู้ขอ พร้อมระบุวัน คาบ และเวลาที่สอนคืนได้
     - `⚠️ สอนแทนได้ แต่สอนคืนไม่ได้`: ครูที่ว่างมาสอนแทนได้ แต่คาบปกติที่สอนห้องนั้นชนกับตารางสอนของครูผู้ขอ
   - แสดงตารางสอนรายวัน (คาบ 0–10) ของครูผู้สอนแทนแต่ละท่าน เพื่อช่วยพิจารณาภาระงานในวันนั้น
2. **รองรับคาบคู่ (Double Periods) แบบแยกแลกอิสระ:**
   - ข้อมูลคาบคู่จากเซลล์ผสานในไฟล์ Excel ถูกถอดมาครบทั้งสองคาบติดกัน ไม่มีคาบหลังตกหล่น
   - แสดงแถบสีเขียวใต้ช่องและป้ายกำกับ `คู่ X-Y` ให้สังเกตง่ายทั้งในหน้าค้นหาและตารางรายสัปดาห์
   - **ไม่บังคับแพ็คคู่:** สามารถคลิกเลือกขอแลกทีละคาบและลงสอนแทนคาบละคนได้อิสระ
3. **ดูตารางสอนรายบุคคลทั้งสัปดาห์ (แท็บ `ดูตารางสอนรายบุคคล`):**
   - ค้นหาชื่อครูเพื่อดูตารางสอนตลอดทั้งสัปดาห์ (จันทร์–ศุกร์ คาบ 0–10) พร้อม Tooltip แสดงรหัสวิชาและช่วงเวลา

## 🧩 โครงสร้างข้อมูล JSON ภายในไฟล์

ข้อมูลตารางสอนถูกฝังอยู่ใน `<script id="schedule-data" type="application/json">` ในรูปแบบ `{ "records": [...], "teachers": [...] }` โดยแต่ละรายการใน `records` มีคีย์ดังนี้:

```json
{
  "t": "ครูวรางคณา ศรีม่วง",
  "g": "ภาษาไทย",
  "d": "พุธ",
  "p": 8,
  "tm": "14.20-15.10",
  "s": "I22202",
  "c": "2/2",
  "l": "246",
  "dp": true,
  "gp": [8, 9]
}
```

- `t` — ชื่อครู
- `g` — กลุ่มสาระการเรียนรู้
- `d` — วัน (`จันทร์` – `ศุกร์`)
- `p` — หมายเลขคาบ (`0` – `10`)
- `tm` — ช่วงเวลาเรียน
- `s` — รหัสวิชา / กิจกรรม (หรือ `null` กรณีไม่มีรหัสวิชา เช่น ประชุมวิชาการ)
- `c` — ห้องเรียน / กลุ่มเรียน (ใช้เป็นกุญแจจับคู่ครูที่สอนห้องเดียวกัน)
- `l` — สถานที่ / หมายเลขห้องสอน
- `dp`, `gp` *(มีเฉพาะคาบคู่)* — ระบุว่าเป็นคาบคู่ (`true`) และช่วงคาบที่ผสานกัน (เช่น `[8, 9]`)
